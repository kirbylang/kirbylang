Concatenates two arrays in to a new list. The result is a list because its length isn't known when the program is compiled.

```kirby
let a = [1, 2, 3];
let b = [4, 5, 6];

@println(@arrConcat(a, b)); // [1, 2, 3, 4, 5, 6]
```
