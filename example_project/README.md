# Example Kirby Project

```
krb run
krb example cat kirby.project.toml
```

## Project

### kirby.project.toml

```toml
# Default Kirby file to run
bin = "bin/main.krb"

# Directory of examples
examples = "examples"
```

### Layout

```
example_project
├── bin/
│   ├── main.krb
├── examples/
│   └── cat.krb
├── kirby.project.toml
└── README.md
```
