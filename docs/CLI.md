# CLI

## Language Version

```sh
kirby -v
kirby --version
```

## REPL

```sh
kirby -r
kirby --repl
```

## Run File

```sh
kirby -f path/to/file.krb
kirby --file path/to/file.krb
```

## Run Code

```sh
kirby -c 'print "Hello, World!";'
kirby --code 'print "Hello, World!";'
```

## Help

```sh
kirby -h
kirby --help
```
