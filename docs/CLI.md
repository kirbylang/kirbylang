# CLI

## Language Version

```sh
krb -v
krb --version
```

## REPL

```sh
krb -r
krb --repl
```

## Run File

```sh
krb -f path/to/file.krb
krb --file path/to/file.krb
```

## Run Code

```sh
krb -c 'print "Hello, World!";'
krb --code 'print "Hello, World!";'
```

## Help

```sh
krb -h
krb --help
```
