# CLI

```
kirby 0.0.0

Usage: krb [-h] [-v] [-r|-f [path]|-x [source]|-l [path]|-p [path]]

Examples:

krb --help                        # -h is the short option
krb --version                     # -v is the short option
krb --file path/to/file.krb       # -f is the short option
krb --repl                        # -r is the short option
krb --compile path/to/file.krb    # -c is the short option
krb --parse path/to/file.krb      # -p is the short option
krb --exec 'print "Hello World";' # -x is the short option
```
